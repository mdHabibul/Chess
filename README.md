# Chess React

A small React chessboard built with Vite. The board renders the standard starting position and supports selecting and moving pieces locally.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Checks

```bash
npm run lint
npm run build
```

## Project structure

- `src/App.jsx` - application shell
- `src/board.jsx` - board state, rendering, and square interactions
- `src/App.css` - board and application styles
- `src/index.css` - global styles
- `vite.config.js` - Vite configuration
